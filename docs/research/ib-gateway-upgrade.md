## Required deployment change

The existing production volume mounts at `/home/ibgateway` and contains the old launcher scripts, IBC, and the `Jts/ibgateway/10.41.1c` executable directory. The new image puts its launcher, IBC, and Gateway installation under the same mount target, so Docker hides them behind the old volume. With `JAVA_HEAP_SIZE` set, the launcher also references a version-specific path inside that directory. Preserve the existing volume for rollback and use a separate settings-only volume via `TWS_SETTINGS_PATH=/home/ibgateway/tws_settings`. Validate authentication and persisted settings there. The new launcher retains container proxy ports 4003 for live and 4004 for paper. [Docker volume behavior](https://docs.docker.com/engine/storage/volumes/#mounting-a-volume-over-existing-data), [10.51.1e Dockerfile](https://github.com/gnzsnz/ib-gateway-docker/blob/013ebd3fa8c2e91b981f4f8f4b65fd519e05f96b/latest/Dockerfile), [10.51.1e proxy and settings code](https://github.com/gnzsnz/ib-gateway-docker/blob/013ebd3fa8c2e91b981f4f8f4b65fd519e05f96b/latest/scripts/common.sh), [Publisher settings persistence guidance](https://github.com/gnzsnz/ib-gateway-docker#preserve-settings-across-containers).

## Connector compatibility

- **Cash readings.** Gateway 10.47 introduced a setting that prefixes currency-level account tags with `$LEDGER-`. IBKR defaults it off for upgrades and on for new users. The connector matches unprefixed tags and initializes missing amounts to zero. Keep the setting off for the current connector and verify USD cash against Gateway before allowing rebalances. Supporting the new setting requires a targeted change to cash parsing. [Account snapshot](../../packages/ibkr-connector/src/ibkr_connector/client.py#L172), [IBKR API release notes](https://www.ibkrguides.com/releasenotes/prod-2026.htm).
- **Order cleanup.** Gateway 10.48 adds deactivated orders to open-order responses. Separately, the client library requests completed orders on startup and puts them in the same cache as working orders. Upstream observed 10.51 returning descriptive text in `completedStatus` with a blank `status` for completed orders. The pinned wrapper uses only `status` for replayed records. The rebalancer treats every cached record except `Filled` or `Cancelled` as eligible for cancellation. An offline probe of the repository's actual selection and cancellation methods with a stub broker confirmed they try to cancel a blank-status completed record and an `Inactive` record. Fix the cleanup to use broker-confirmed working orders with an explicit policy for deactivated orders, and test against completed history. The upstream 10.51 fix is for replay, separate from live order-status callbacks. PyPI's `2.1.0` release does not contain that fix. This review did not capture 10.51.1e's actual responses with the pinned client's negotiated protocol, which caps at version 178. [Open order filter](../../packages/ibkr-connector/src/ibkr_connector/client.py#L453), [Cancellation loop](../../packages/ibkr-connector/src/ibkr_connector/rebalancer.py#L312), [Pinned startup behavior](https://github.com/ib-api-reloaded/ib_async/blob/v2.0.1/ib_async/ib.py), [Pinned cache behavior](https://github.com/ib-api-reloaded/ib_async/blob/v2.0.1/ib_async/wrapper.py), [Pinned protocol](https://github.com/ib-api-reloaded/ib_async/blob/v2.0.1/ib_async/client.py), [10.51 status fix](https://github.com/ib-api-reloaded/ib_async/commit/bca7ca6e3018fc7d1ca10e2535cda8f45caaa2a0), [2.1.0 package](https://pypi.org/project/ib-async/2.1.0/), [2.1.0 source comparison](https://github.com/ib-api-reloaded/ib_async/compare/v2.0.1...v2.1.0).
- **Other API changes.** The connector uses stock/ETF positions, stock contract qualification, quote snapshots, and market/limit orders with explicit time in force. The 10.51 position exchange correction does not affect the position fields the connector reads. The intervening removals for fundamentals and additions for odd lots, hedges, and conditional orders do not change calls this connector makes. No portfolio-calculation rewrite is indicated by these changes. [Position and pricing code](../../packages/ibkr-connector/src/ibkr_connector/client.py#L122), [Order submission](../../packages/ibkr-connector/src/ibkr_connector/client.py#L410), [IBKR API release notes](https://www.ibkrguides.com/releasenotes/prod-2026.htm).
